# Einheit 49: Bedeutung der Neutrino-Größen vor einem Datenvergleich

2026-10-18, Ausgang 5c6c270. Quellenverständnis, keine aktuellen Residuen.

H016 PDF9 und H007 PDF9/10 vollständig lesen: Definition, Zustandsliste,
Realitätsanspruch und genannte Interpretation getrennt festhalten. H007
bleibt eine spätere Redaktion nach einem Manuskript, H010 eine Übertragung.

Im H010-C-Code Namensauswahl, Filter und berechnete Größe statisch
nachverfolgen. Keine Originalprogramme ausführen, keine Quellwerte ändern.
Ein Tabelleneintrag beweist weder aktive Übersetzung noch Ausführung.
Kompilierungsauswahl, Eingabebereich und Filter deshalb getrennt ausweisen.

Ziel ist eine überprüfbare Zuordnungstabelle samt offener Messbrücke.
Ohne Definition einer experimentell zugänglichen Größe keine direkten
Neutrino-Massenresiduen bilden und keine passenden modernen Namen einsetzen.
