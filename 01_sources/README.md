# Quellen

Dieser Ordner trennt Quellenarten:

- `heim_primary/`: Heim-Originale, Heim-nahe Vortraege, direkte Massenformel-Dokumente.
- `heim_secondary/`: Kommentare, Rekonstruktionen, spaetere Erweiterungen.
- `mainstream_reference/`: PDG, NIST/CODATA, Standardmodell-Referenzen.

Lokale Dateien sollten nicht ungeprueft gesammelt werden. Jede lokale Kopie braucht eine Zeile im Quellenregister mit URL, Abrufdatum, Dateiname und Status.
