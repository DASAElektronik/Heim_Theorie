# Rekonstruktion

Hier entsteht die eigentliche technische Arbeit.

## Erste Teilaufgabe

Rekonstruktion der Massenformel:

1. Alle Symbole aus Heim-Quelle erfassen.
2. Einheiten und Dimensionsanalyse pruefen.
3. Rechenweg als Pseudocode formulieren.
4. Implementierung schreiben.
5. Ergebnisse gegen Heim-Tabellen vergleichen.
6. Ergebnisse gegen heutige PDG/NIST-Werte vergleichen.

## Evidence Layers

- `formula_library/`: source-checked formula transcriptions, normalization decisions, and implementation gate.
- `external_evidence/`: online or secondary-source claims used only as research leads for drift analysis.
