# NORM-1989-FPHI-NAMING

Date: 2026-05-15

Decision ID resolved:

- `NORM-1989-FPHI-005`

## Decision

Use stable implementation names for 1989 F/Phi subscripts and functions:

```text
Q_n, Q_m, Q_p, Q_sigma
N_3, N_4, N_5, N_6
N_of_k
N_prime_of_k
eta_q_k
eta_q_1
eta_1_k
theta_q_1
```

This decision is naming-only.

## Rules

- Do not use this naming decision to resolve B50 sign scope.
- Keep comma-subscript source forms visible in source transcription.
- If a later decision maps an `eta_*` name to `eta_k_q`, it must use named arguments and cite that decision.
