# NORM-1989-NEUTRINO-PHI-GLYPH

Date: 2026-05-15

Decision ID resolved:

- `NORM-1989-NEUTRINO-002`

## Decision

Use `phi` as the canonical ASCII implementation name for the 1989 self-coupling glyph family.

Source glyphs `phi` and variant-shaped `phi` are preserved in source notes when visually relevant, but they map to:

```text
phi
phi_0
```

## Rules

- Do not confuse uppercase `Phi` with lowercase `phi`.
- Do not use this glyph decision to normalize B49 scope.
- `Phi + phi_0` in the neutrino formula keeps two separate terms.
