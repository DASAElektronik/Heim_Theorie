# Analyse

Analysefragen:

- Wie gross sind absolute und relative Abweichungen?
- Liegen Abweichungen innerhalb der historischen oder heutigen Unsicherheiten?

- Welche Werte waren echte Vorhersagen?
- Wie viele freie Parameter wurden verwendet?
- Ist der Ansatz dimensionskonsistent?
- Gibt es Konflikte mit heutigen Standardmodell-Daten?
