# Rohdaten und Referenzdaten

Fuer den ersten Test brauchen wir vor allem kuratierte Referenzwerte:

- Teilchenmassen, Lebensdauern, Breiten und Unsicherheiten aus PDG.
- Naturkonstanten aus NIST/CODATA.
- Spaeter optional HEPData-Tabellen oder CERN Open Data, falls Heim eine konkrete Signatur jenseits von Massenwerten liefert.
